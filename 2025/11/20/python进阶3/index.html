Linux基础

文件操纵相关

查看 创建

  • ls 查看当前路径下的目录信息
    命令下还有写参数
  1. -l 以列表方式显示，默认是字节，更详细 可以省略为ll
  2. -h 只能显示文件的大小
  3. -a 显示隐藏文件和隐藏目录 通过-a可以查看到当前目录除了一般的目录还有.和.. 储存的分别是当前目录和上一级目录的信息 方便我们使用cd.和cd .. ##隐藏文件一般都以点开头，只要创建文件时以点开头，系统自动判定这个文件为隐藏文件##
  • tree 以树状方式显示目录
  • pwd 查看当前目录路径
  • clear 清除终端内容
  • cd change directory的缩写 改变目录
    如果直接使用cd命令，则是回到主目录
    cd ..切换到上一级目录
    cd .切换到当前目录 主要用于创建文件夹表示当前目录
    cd - 切换到上一次目录
    涉及到目录的切换，需要提到两个概念
    绝对路径和相对路径 绝对路径指的是相对于整个系统都能找到的地址 相对路径则是相对于当前文件夹 绝对路径一般在文件目录前面加上/来 确保文件的绝对路径
  • touch 文件名 创建指定文件
  • mkdir 创建目录
    -p 创建文多级件夹时，不需要一次一次的去创建，可以直接使用-p参数 例如 mkdir /aa/bb/cc -p
  • rm 文件名 删除指定文件
    rm [options] name…
    options 包含了 r f i
    r 递归删除，将目录及以下目录亦逐一删除
    i 删除前逐一询问
    f 即使原档案属性设为唯读，亦直接删除，无需逐一确认。
    rmdir 删除空目录
    rm -rf 文件夹
    复制，移动
  • cp 例如 cp 路径 路径
    和删除类似 再拷贝文件夹时可以使用-r来确保文件夹内的文件也被拷贝，除-r外还有-i 交互式提醒，-v显示拷贝后的路径描述
  • mv 移动
    mv的写法和cp类似，但是文件夹移动时不需要写-r来确报文件的全部移动，其实可以利用mv来实现文件和文件夹的重命名，例如mv a b
    Linux命令的格式大部分为command [-options] [parameter] 即命令 选项 参数

进阶命令

重定向命令
重定向也称作输出重定向，把在终端执行命令的结果保存在目标文件

如果文件存在，会覆盖原有文件内容，相当于文件操作的w模式

如果文件存在，会追加写入文件尾部，相当于文件操作的a模式
例如ls > a.txt 就会将ls命令执行的结果写入到文件a.txt文件里
查看文件内容命令

  • cat 查看小型文件
    cat命令支持一次性查看多个文件，例如cat a.txt b.txt会一次性全部打印到终端上，这个时候可以使用重定向 将两个文件全部整合到一个文件里 例如 cat a.txt b.txt > c.txt
  • more 查看大型文件
    如果使用more查看文件，那么会新建立一个页面，用来查看，f是翻页(forward),b是backward也就是回退，q是推出
  • | 管道，一个命令的输出可以通过管道做为另一个命令的输入，相当于一个容器
    例如tree | more，就会将more的结果传入more命令，more就会创建新窗口来查看传入的结果
    链接命令
    软链接 类似于Windows下的快捷方式，当一个源文件的目录层级比较深，我们想要方便使用它可以给源文件创建一个软链接soft 这个软链接真的是直译 ln -s
    例如 ln -s ./A/B/C/hello.py hello_s1.py 这个是用相对路径创建的软链接 需要注意的是，如果使用相对路径创建软链接的话，那么在移动创建的软链接后，使用相对路径创建的软链接就会作废 不仅可以创建文件的软链接，还可以创建文件夹的软链接，例如 ln -s /home/python/Desktop/A A_s
    查找文件内容命令
    grep 查找和搜索文件内容
  • -v 显示不包含匹配文本的所有行
  • -n 显示匹配行号
  • -i 忽略大小写
    grep x x.txt -nv
    或者可以使用正则表达式 还是一样^为开始，$为字符结束 但是可以使用 ^b 来表示任何以b为开头的字符 b$表示以b为结尾的字符 b.b来表示匹配的字符必须以b为开头且为结尾 .匹配一个非换行符的字符
    查找文件的命令
  • find 在指定目录下查找符合条件的文件 使用方法为find 文件目录 参数 “文件名称” 这里的参数大多指的是-name 即以名称搜索
    还能使用 -name参数 表示根据文件明查找文件
    说的这里就必须要说一个东西，叫做通配符 是一种特殊语句，用来模糊搜索文件主要有*和？ *代表0个或多个任意字符 ？代表任意一个字符
    压缩和解压缩
    在这里介绍.gz和.bz2 都需要tar命令
    其参数有
    -c 创建打包文件
    -v 显示打包或者解包的详细信息
    -f 指定文件名称，必须放到所有选项后面
    -z 压缩(.gz)
    -j 压缩(.bz2)
    -x 解压缩
    -C 解压缩到指定目录
    需要注意的是 压缩前必须打包 打包是没有压缩功能的所以正确的压缩为 tar -zcvf 323.tar.gz *.txt 解锁的为 tar -zxvf 1.tar.gz 把c换成了x

文件权限命令

我们知道ls -lh可以查看文件夹内所有文件的详细信息，大概是
左数第一列是文件类型和权限 第三列 用户名 第四列 用户组 第五列 文件大小 第六列 文件修改时间 第七列 文件名
其他都比较好理解 需要特别注意的是图片中的最左边 文件的类型和权限

  • 文件类型的说明 ##文件类型第一个字符表示是文件还是文件夹 后面9个字符是以三个为一组的三元字符 代表着文件的权限配置##
  • 表示普通文件 d表示文件夹 例如 -rw-rw-r– 和frwxerwxr-x
  • 文件权限的说明
  1. 有三个三元组字符组成
  2. 第一个三元字符组代表文件所有者用户的权限
  3. 第二个代表文件用户组的权限
  4. 第三个代表其它用户的权限
  5. r表示可读 w表示可写
  6. x表示可执行 -表示没权限
    例如 drwxrwxr-x d表示文件夹，第一个三元元组rwx表示文件的所有者可以读写执行，第二个三元元组rwx表示同用户组可以读写执行，第三个三元组r-x代表除所有者和同用户组的用户，只能读和执行
    权限命令的修改
    权限的修改主要利用的是chmod命令 这里的chmod应该是change mod
    修改的方式一般有两种 字母法和数字法
    字母的用法是 change u/g/0/a+/-/=rwx 文件名
    u user表示当前该文件的所有者
    g group表示用户组
    o other表示其它
    a all表示所有用户
    还有就是这里出现了操作符 即 +增加权限 -撤销权限 =设置权限
    例如chmod u-w a.py u表示user 撤销user的写的权限
    这里有一点需要注意 在linux里不是编译好的文件 执行时需要在文本内写上#！解释器目录 即可实现在命令框内输入./执行时直接执行 不要再在命令框内输入python3然后才能执行
    还有一种写法是叫做数字法 即chmod 权限值 文件名 类似于chmod 777 文件
    r 可读 权限值是4
    w 可写 权限值是2
    x 可执行 权限值是1
  • 无任何权限 权限值是0
    这里的权限如果用数字的形式来表示的话都是以相加的形式确认 每一位数字代表着一个三元元组 如果数字不全 那么都是以后面优先 从后面往前面赶例如 777 就代表着所有三元分组都是可读写执行的 如果是chmod 4 那么就代表的是最后三元元组的其它有可读权限 全零即代表着任何人都没有权限接触

远程登陆

基于ssh命令的scp命令是一个安全的远程文件拷贝的命令，也就是说需要保证服务端和客户端都安装了对应的ssh软甲
scp命令的格式

  1. 远程拷贝文件
    scp 本地文件 远程服务器用户名@远程服务器ip地址：指定拷贝到远程服务器的路径
    scp 远程服务器用户名@远程服务器ip地址：远程服务器文件 指定拷贝到本地的路径
  2. 远程拷贝目录
    scp -r 本地目录 远程服务器用户名@远程服务器ip地址:指定拷贝到远程服务器的路径
    scp -r 远程服务器用户名@远程服务器ip地址:远程服务器目录 指定拷贝到本地的路径
    软件安装的和卸载
    在linux中可以使用离线安装和在线安装
  • deb
    deb是ubuntu的安装包格式 可以使用dpkg命令进行安装 例如 sudo dpkg -i deb安装包
  • apt-get
    在线安装的方式 主要应用于从互联网的软件仓库中搜索，安装，升级，卸载软件
    同样的卸载方式同样有两种 一种deb文件格式的卸载 一种apt-get安装的卸载
  • sudo dpkg -r 安装包名
  • sudo apt-get remove 安装包名
vim

vim一般有三个工作模式

  1. 命令模式
  2. 编辑模式
  3. 末行模式
    末行模式的参数为:q,:wq,:x,:q! 意思分别是 退出，保存并推出，保存退出，强制退出
    一般通过vim进入文件 都是命令模式 输入i进入编辑模式 再摁一次esc即可进入命令模式 编写完成如果像保存并推出就可以摁shift和：即可进入末行模式 然后输入wq既可以保存并推出
多任务

多任务有两种实现方式

  1. 并发
    也就是anscio的形式 交替执行
  2. 并行
    也就是多进程的形式 同时执行
